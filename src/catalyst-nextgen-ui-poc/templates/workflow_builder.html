Quick Start Guide

  1. 1. Name your workflow - Give it a clear, descriptive name and unique key
  2. 2. Add steps - Click "✨ Templates" for pre-built steps, or drag tools from the toolbox
  3. 3. Configure steps - Click any step to expand and edit. Use {document_content} and {previous_output} in prompts
  4. 4. Set up options - Add variables like {topic} in prompts, then click + to create user options
  5. 5. Validate & save - Fix any errors shown above, then click "Save Direction"

💡 Pro Tips:

  • Drag the ⋮⋮ handle to reorder steps
  • Press ESC to collapse expanded steps
  • Click "📥 Export" to download your workflow as JSON
